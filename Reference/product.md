# 产品范围与创作验收

核对日期：2026-10-11。本文件定义用户目标和验收，工程实现分别归[模块索引](README.md)。当前仍为原型，存在的 API/界面不代表真实作品质量已验收，阶段记录见 [PLAN](../PLAN.md)。

## 用户与创作模型

面向短视频创作者、电商/营销人员和需要生成式创作的普通用户。项目把节点画布生成、时间线剪辑和自然语言 Agent 编排放在同一桌面工作流：用户从想法、产品图或分镜脚本产生素材，再剪辑、加字幕/音乐并导出。

一个项目有多个画布和一个多轨时间线。画布组织输入→生成→output 的链路，结果可为图片或视频，也新增本地白模视频；时间线可加入普通媒体或引用画布输出的智能片段。素材、任务和对话用于辅助创作，不替代画布工作区。

生成支持文生图、图生图、文生视频、图生视频、视频编辑/延长的适配入口，具体模型能力依实际 Provider 配置和输出验证。更新采用惰性策略：画布变化后时间线引用过期，用户决定何时生成和更新，避免自动发生费用或覆盖剪辑。

## MVP 验收场景

1. 产品图短视频：导入产品图，提出目标时长/主体/字幕要求；Agent 搭建图生视频画布，生成结果加入时间线，添加用户提供的音乐及字幕，导出可回放 MP4。
2. 分镜短片：输入三个各约 5 秒镜头的分镜，逐镜头生成并人工检查素材，按顺序编排，添加字幕/音乐和明确支持的效果，导出约 15 秒作品。不能用当前片段淡入淡出宣称真实交叉转场完成。
3. 本地白模：创建基础几何体与镜头运动场景，保存并生成，检查视频尺寸/时长/帧率/运动，再接入时间线或下游视频生成；下游 AI 仍需对应服务配置。

每个场景保存输入素材、操作、实际模型/工具配置、任务状态/日志、生成结果、成片与耗时；核对主体、时长、比例、字幕可读性、音乐/原声、裁剪入点和音画同步，并验证失败、取消、重复提交和修改后更新。前两个场景真实跑通是 MVP 的作品闭环验收要求，mock 或接口存在不能替代它。

## 阶段、范围与风险

Phase 0 优先单画布→素材→时间线→导出闭环；Phase 1 完善多轨、惰性更新、预设和子画布；Phase 2 验证 Agent 多镜头编排；Phase 3 建设分发与自动更新。当前目标平台 Windows/macOS，当前验证主要来自 Windows；用户提供本地 API Key，后端统一代理/订阅额度模式尚未确定。

当前不做：画布通用合成/调色/转场节点、超过两层嵌套、实时协作、移动端、云渲染、商业付费墙、多画布分屏或多机位。C++ 媒体核心/硬件加速和 Qt 原生桌面是保留的长期设计方向，未成为当前工程迁移任务，见[决策](decisions.md)。

主要风险是第三方成本/限流与未知提交结果、结果可复现性、缓存和跨画布更新、Agent 操作质量、CPU/GPU 资源竞争及跨平台媒体兼容。重试应先查已有状态，不能把 retryable 标记理解为任意副作用可直接重放。
