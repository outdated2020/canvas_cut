# 必要历史决策与当前状态

原设计与评审主要形成于 2026-08-15，布局于 2026-08-19 调整；本页于 2026-10-11 按当前源码整理。历史“设计解决”仅表示当时的文档决定，不能视为代码或真实服务验收。具体规则唯一归模块文档，后续计划保留于 [PLAN](../PLAN.md)。

## 保留的评审待办

- L3/L4：ASS/libass 字体路径/中文转义、双片段音频交叉转场待实现；当前 drawtext 和片段 fade 不能替代，归[媒体](modules/core-media.md)。
- L2/L6：本地媒体 protocol、资产 GC/LRU、缩略图/代理/元数据索引待建设，分别归 UI/桥接/存储/缓存的接口协作，不共享清理策略所有权。
- L5：FFmpeg 许可/分发与应用签名/公证/自动更新待建设，归[工程](modules/engineering.md)。
- L8：CLI 子进程凭证处理已有 host 环境清理和固定 launcher；完整隔离/审批仍待设计，归[Agent 工具](modules/agent-tools.md)与宿主注入。
- M6：音乐获取服务未定；当前创作验收使用用户提供的音乐文件，不暗示已有版权音乐库。
- M9：历史暂缓费用护栏；现有步数/字符预算并非累计费用预算，后续 Run Token/费用/全局并发见 PLAN。
- L10：Phase 0 以可回放成片闭环收敛，保留真实 Provider/媒体验收，不用更多接口替代作品验收。
- S5/N1：当前调用方主要轮询，只有画布变更通知已有接线；旧 job:update UI 推送、大 payload、优雅排空仍不是普遍实现。
- D6/D8 和 S1–S7 的纯文档同步在本轮由[迁移对照](migration.md)收敛；业务实现状态以模块偏差/PLAN 为准。

## 后续设计方向

保留而未实施的方向包括：headless 服务、额外 Provider、云代理/商业计费、自动保存/版本迁移/备份、跨文件恢复、Undo/Redo、高级字幕/特效/贴纸双后端一致性、多选/ripple/精确吸附、分段渲染缓存、用户附件/语音/Web Search、Agent 输入/审批/暂停续跑、多 Agent、精确预算和记忆检索。

这些是产品和工程的候选建设事项，不是已承诺接口。新增工作先指定唯一模块归属、明确兼容与验收，再更新 [PLAN](../PLAN.md)，避免恢复一套与现行模块说明并行的设计规则。
