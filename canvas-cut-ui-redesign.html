② 现版问题与优先级

基于截图（cc_win.png / after_new_canvas4.png / test_transcript.png）与 style.css 逐条核对。

P0 · 层次
灰阶差距太小，面板边界靠猜
现版 #141414 → #1a1a1a → #222226 三级背景几乎不可辨，界面糊成一片灰。改版拉开为 #0f1115 → #16181d → #1d2026 并整体偏冷，输入框反而更暗（#10131a）形成「内凹」隐喻，层次一眼可读。
P0 · 主 CTA
核心按钮不显眼，橙色乱用
「New canvas」是橙字灰底，视觉重量还不如旁边的上传图标（也是橙的）。改版：主 CTA 一律实心橙底 + 深色字，且上移到项目栏常驻；橙色只留给 CTA 和当前态，其余图标回归灰阶。
P0 · 信息架构
Agent 产品却看不到 Agent 入口
首屏左栏被 6 张模板卡占满，AI 对话输入框完全不可见——这是产品的核心能力。改版：模板压缩为 4 张，AI 输入框固定在左栏底部，并加「模型名」提示，让「对话创作」成为第一动线。
P1 · 空态
三个空态三种态度
Assets 是孤零零文件夹图标（无按钮）、Canvas 是「No canvas yet」（有按钮）、Viewer 只有一行被截断的「Drop media…」。改版统一空态公式：图标 + 一句价值描述 + 一个主按钮 + 一条辅助提示。
P1 · 色彩
模板卡六种高饱和色，像六个产品
紫 / 蓝 / 橙 / 绿 / 粉 / 青竖条互相打架，且都和品牌橙冲突。改版：彩色只保留品牌橙一处，模板图标统一「10% 橙底 + 橙色线性图标」，靠文案区分业务，整体立刻安静、高级。
P1 · 时间线
空项目显示 40 分钟假刻度
项目里一个片段都没有，刻度却从 00:00:00 排到 00:40:00，是纯噪音。改版：空态时间线只显示引导文案 + 关键动作，有素材后再渲染刻度。
P2 · 细节
图标语言不统一、无 tooltip
侧栏卡是彩色线性图标、顶栏是单色、时间线又是另一种描边风格；工具条 5 个 icon-only 按钮没有 tooltip。改版：统一 1.5px 线性图标，所有 icon-only 按钮加 title/tooltip（见 mockup 悬停）。
P2 · 标题栏
titlebar 蓝紫色与主界面断层
截图中原生标题栏是蓝黑色，与 body 的 #141414 明显两个世界。改版：自绘 titlebar 或把原生栏颜色对齐到 #16181d，顶栏与内容用 1px 边框分隔即可。
